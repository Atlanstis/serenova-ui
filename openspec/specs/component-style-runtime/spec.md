# component-style-runtime Specification

## Purpose

定义组件在浏览器客户端使用时自动获得基础样式的公共行为，覆盖首次显示、重复挂载、多应用共存、按需依赖和实例变量覆盖，使使用者直接渲染组件即可获得默认外观。

## Requirements

### Requirement: 使用组件自动获得样式

组件 MUST 在浏览器首次显示时具备自身及必要依赖的完整基础样式，样式初始化由组件使用过程自动完成。包根具名导入、组件子路径和插件注册后的使用 MUST 具有一致结果。仅加载模块或注册插件 MUST 保持 DOM 原状。

#### Scenario: 直接使用组件自动加载样式

- **WHEN** 客户端应用通过任一受支持入口使用 Button 且未导入组件库 CSS
- **THEN** 首次显示具有默认外观，后续改变尺寸、语义、文字、Ghost、禁用或加载状态时样式完整

#### Scenario: 仅注册组件

- **WHEN** 应用仅导入组件或安装插件但尚未渲染组件
- **THEN** 文档保持原有样式集合，组件样式在首次渲染时挂载

### Requirement: 重复使用共享基础样式且主题隔离

相同版本的相同组件样式 MUST 在同一文档内复用，多实例和多个 Vue 应用 MUST 共享单份基础样式。卸载一个实例 MUST 保持其他实例的样式有效；重新挂载 MUST 保持外观正确。主题值 MUST 保持实例隔离，主题覆盖作用域 MUST 限于对应实例，全局根节点保持原有主题与基础样式。

#### Scenario: 多应用重复使用

- **WHEN** 同一文档中两个应用分别使用不同主题的 Button 并卸载其中一个
- **THEN** 同一基础样式只挂载一次，剩余按钮继续保留自身外观

#### Scenario: 卸载后重新使用

- **WHEN** 所有按钮卸载后再次挂载按钮
- **THEN** 默认样式正常且同一基础样式保持单份

### Requirement: 样式依赖边界与原生覆盖

运行时样式 MUST 仅包含所用组件及必要依赖；独立图标 MUST 通过内联 SVG 呈现，纯主题预设 MUST 仅提供主题数据。消费端原生 style 覆盖 MUST 在自动加载基础样式的接入方式下生效。

#### Scenario: 覆盖实例变量

- **WHEN** 使用者通过 style 覆盖按钮公开变量
- **THEN** 自动样式保持默认外观且被覆盖字段采用使用者指定值

#### Scenario: 独立使用图标

- **WHEN** 消费应用只从 icons 入口使用一个图标
- **THEN** 图标通过自身内联 SVG 正常显示，样式依赖仅限于该图标自身

# component-style-runtime Specification

## Purpose

定义组件在浏览器客户端使用时自动获得基础样式的公共行为，覆盖首次显示、重复挂载、多应用共存、按需依赖和实例变量覆盖，使使用者无需手工导入样式，也无需配置主题提供者即可使用组件。

## Requirements

### Requirement: 使用组件自动获得样式

组件 MUST 在浏览器首次显示时具备自身及必要依赖的完整基础样式，不要求消费端显式导入 CSS、额外初始化或配置 Provider。包根具名导入、组件子路径和插件注册后的使用 MUST 具有一致结果。仅加载模块或注册插件 MUST 不修改 DOM。

#### Scenario: 无 CSS 导入使用组件

- **WHEN** 客户端应用通过任一受支持入口使用 Button 且未导入组件库 CSS
- **THEN** 首次显示具有默认外观，后续改变尺寸、语义、文字、Ghost、禁用或加载状态时样式完整

#### Scenario: 仅注册组件

- **WHEN** 应用仅导入组件或安装插件但尚未渲染组件
- **THEN** 不向文档挂载该组件样式

### Requirement: 重复使用共享基础样式且主题隔离

相同版本的相同组件样式 MUST 在同一文档内复用，多实例和多个 Vue 应用 MUST 不重复插入同一基础样式。卸载一个实例 MUST 不影响其他实例；重新挂载 MUST 保持外观正确。主题值 MUST 保持实例隔离，不向全局根节点写入主题或 reset。

#### Scenario: 多应用重复使用

- **WHEN** 同一文档中两个应用分别使用不同主题的 Button 并卸载其中一个
- **THEN** 同一基础样式只挂载一次，剩余按钮继续保留自身外观

#### Scenario: 卸载后重新使用

- **WHEN** 所有按钮卸载后再次挂载按钮
- **THEN** 默认样式正常且不产生重复基础样式

### Requirement: 样式依赖边界与原生覆盖

运行时样式 MUST 仅包含所用组件及必要依赖；独立图标与纯主题预设 MUST 不引入 Button 样式。消费端原生 style 覆盖 MUST 继续生效，MUST 不要求任何独立 CSS 入口。

#### Scenario: 覆盖实例变量

- **WHEN** 使用者通过 style 覆盖按钮公开变量
- **THEN** 自动样式保持默认外观且被覆盖字段采用使用者指定值

#### Scenario: 独立使用图标

- **WHEN** 消费应用只从 icons 入口使用一个图标
- **THEN** 图标正常显示且不加载 Button 样式

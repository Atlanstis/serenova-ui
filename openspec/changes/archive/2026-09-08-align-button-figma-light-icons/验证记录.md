## 实现说明与迁移

- 旧 default 需要根据意图选择 primary、primary+ghost 或 text；danger 及 Danger token 改为 error/Error。
- darkPreset 和 themes/dark 已移除；Provider 仍允许消费端自定义颜色，测试用浅色自定义预设验证隔离，未删除相关能力。
- 图标只支持包根和 icons 集合入口。单图标子路径未新增，包测试明确验证拒绝解析。
- Figma 整节点 SVG 导出加入了画布矩形。已用 MCP 确认六个来源节点 fills 为空，生成器只去除此明确匹配的背景，并保留真实路径；按用户补充要求，assets 同样去除背景及固定颜色，清单分别记录清理前后的哈希。
- XML 解析使用开发依赖 @xmldom/xmldom 0.9.12，package.json 与锁文件已同步；解析警告和错误均终止转换。保留 none 和透明度，其余颜色转为 currentColor，缺省填充也继承外部 color。
- 字体由消费端提供 Noto Sans SC 或回退 sans-serif；库不下载或捆绑字体。按用户补充要求，Figma Icon 页已将 Loading 收敛为独立组件（20:2），删除 90/180/270 三个变体和组件集，清除原型切换；65 个已有实例仍引用 20:2，截图确认形状保持一致。

# 公共组件轻量化无障碍规范

- 本规范仅适用于公共组件，不约束测试 Fixture、Storybook 辅助组件等内部实现。
- 公共组件涉及交互时，必须明确梳理鼠标、键盘和焦点相关行为。
- 组件需要支持键盘操作时，应遵循用户熟悉的按键习惯。
- 鼠标与键盘触发同一操作时，必须复用同一业务处理路径，避免行为分叉。
- 交互状态必须使用含义清晰的命名和派生逻辑表达，避免将复杂判断散落在模板中。
- 不得无条件阻止原生事件或焦点行为；使用 `preventDefault`、`stopPropagation` 等操作时，代码必须明确体现原因和适用条件。
- 键盘行为沿用现有组件测试体系；涉及真实焦点或浏览器键盘事件时，使用 `*.integration.spec.ts`，不新增独立的无障碍测试体系。
- 当前不以完整 WCAG 合规为目标，不强制新增 `aria-*`、`role`、特定 HTML 语义标签、可访问名称、屏幕阅读器适配或自动化扫描工具。
- 不得仅为满足本规范而引入额外依赖或复杂抽象；后续可根据组件成熟度逐步增强。

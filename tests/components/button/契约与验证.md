## 2026-09-09：Figma 间距核对

通过 Figma MCP 读取 Button 页面 `3:60`，核对主按钮 `6:2`、`6:26`、`6:50`、Ghost `37:178` 和双图标实例 `77:1618`：图标宽度 16px、图文间距 8px，三档水平留白为 12/16/20px，最小宽度为 64/80/96px。描边为 1px INSIDE，且 `strokesIncludedInLayout=false`。

原 CSS 在水平 padding 外另计两侧边框，导致内容撑开的按钮额外增加 2px。现将边框计入水平留白，保留原有主题令牌及最小宽度。例如 Figma 中号双图标“编辑”为 108px；中号纯文字“编辑”为 80px，其左右各 26px 留白来自最小宽度。

当前源码的 8px 图文间距在独立组件及默认 Provider 下均正常，尚未复现反馈中的零间距，需结合具体消费场景继续定位。鼠标、Enter、Space、焦点与禁用逻辑无改动。

本次公共契约分析与测试范围：

- unit：适用，复用既有 Props 默认值、Slots、click、状态切换、源码类型和公共出口测试；没有新增 API 或改变这些契约。
- integration：适用，新增最小 Fixture，从插槽内容和图标的实际矩形验证五种类型、三档尺寸、纯文字、单侧/双侧图标、加载、Ghost 及主题覆盖；不依赖内部状态。
- E2E：适用现有全量/按需消费、图标组合及表单流程回归；本次无新增业务流程，不另增 E2E 场景。
- package：适用，CSS 构建产物变化，继续验证发布契约；公共导出和类型签名未改变，无需修改出口测试或共享类型消费 Fixture。

## 2026-09-09：独立 text 外观与语义类型组合

本节替代前述 `variant="text"` 用法。`buttonVariants` 收敛为 primary/warning/success/error，新增 `text?: boolean`，默认 false。`text` 为 true 时优先于 `ghost`，可与四种类型、三档尺寸、iconOnly、disabled、loading 组合。保留插槽顺序、加载替换图标、原生 click/键盘/焦点契约；文字模式退出后恢复原类型的实心或 Ghost 尺寸和反馈。

文字外观使用独立 `textButtonColor`、`textButtonColorHover`、`textButtonColorPressed`、`textButtonColorDisabled` 颜色组，支持四种语义后缀及 Primary 基础覆盖；加载与禁用共用 Disabled，实心/Ghost 配色不受文字专用覆盖影响。删除原 `*Text` 变体字段及 `textColorDisabled` 组件字段，迁移说明见 `docs/styling-and-theming.md`。源码根入口、单组件入口、共享包消费 Fixture 和 ESM 枚举契约均已同步。

分层范围与结果：

- unit：适用，覆盖默认值、四种语义与 text/ghost 优先级、动态切换、Slots、click、禁用/加载和公共类型出口；64 项通过。
- integration：适用，四种文字状态色及独立主题覆盖、透明背景与无描边、鼠标/Enter/Space 一致性、焦点、无波纹、加载、退出 text 恢复 Ghost、全部尺寸与间距；全量 27 项通过。
- E2E：适用，公共 API 迁移影响按需消费，新增从 dist 入口加载的错误色文字操作、键盘激活及加载阻断流程；全量 4 项通过。
- package：适用，枚举及主题声明变化；共享消费 Fixture 验证新属性和旧字段拒绝，发布产物 ESM/CJS、声明、CSS、插件、导出映射、npm 文件边界检查通过。

`pnpm type-check`、`pnpm test:unit`、`pnpm test:integration`、`pnpm build`、`pnpm test:e2e:built`、`pnpm test:package:built` 均通过；后两项共用本次最新构建。

## 2026-09-09：同步文字焦点环几何

`text && !iconOnly` 聚焦时改用不参与布局、不可拦截指针的伪元素外环，围绕内容四周保留 4px 内侧留白，默认 32px 高、2px 描边、9px 圆角，对齐 Figma 的 12 个文字焦点变体。保留按钮三档点击高度、排列宽度、图文间距和类型焦点色；失焦后不绘制外环。纯图标、普通和 Ghost 按钮继续沿用原生 outline。主题 `focusOffset` 仅用于原生外环，文字外环采用固定内侧留白；`focusWidth` 与类型焦点色仍生效。

公共 Props、Slots、Events、状态派生、源码类型和出口无变更，因此 unit 沿用现有行为与出口契约（64 项通过）。integration 适用：新增三档实际焦点几何、布局稳定、失焦隐藏和普通/纯图标保留原生外环测试，并验证四种语义颜色及带图标内容（全量 29 项通过）。E2E 复用已存在的四种消费关键流程，无新增业务链路（4 项通过）。package 适用 CSS 产物回归，发布契约检查通过；无需调整公共类型消费 Fixture。

本次依据以上公共契约保留 Slots、Events、外观和状态回归，补充 type 动态透传、默认不提交、submit/reset 的鼠标与键盘一致性及禁用/加载阻断；源码类型和两个公共出口验证旧 API 删除。unit、integration、E2E、package 均适用，理由见上表，实际结果见 `openspec/changes/archive/2026-09-09-remove-button-native-type/验证记录.md`。

## 自动样式与客户端支持契约

公共 Props、默认值、Slots、Events、原生语义及类型出口保持不变。Button 使用时自动获得完整样式，无 Provider 回退浅色；Provider 保留默认插槽、无包装、响应式继承、重置和 Teleport 上下文。独立图标保持 size=24、currentColor、无业务插槽事件及无需 CSS，不携带按钮规则。边界新增多应用同文档样式去重、卸载后重挂载以及旧 CSS 入口移除。仅支持客户端，不再验证 SSR 或 hydration。

- unit 适用：输入输出、主题覆盖和默认回退、类型与导出沿用黑盒测试。
- integration 适用：真实计算样式、主题多应用隔离、动态状态及样式挂载生命周期。
- E2E 适用：dist 包根、子路径及插件无需 CSS 的真实消费，验证原生 style 覆盖及样式去重。
- package 适用：自动样式不能破坏 ESM、声明、自动样式、依赖边界、tree shaking 或 npm 文件范围；Node 导入不代表 SSR。

本次验证已通过：unit 66 项、integration 38 项、Chromium E2E 5 项，以及 package、类型检查、lint 和格式检查；最终样式专项复验通过。主规格已同步，临时变更目录已删除。

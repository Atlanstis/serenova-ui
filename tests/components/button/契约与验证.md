# 公共契约与验证

| 契约          | 输入、默认值与可观察结果                                                                                                                                                                                                  |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Props         | variant 默认 primary，支持 primary/warning/success/error/text；size 默认 medium，支持 small/medium/large；nativeType 默认 button，支持 button/submit/reset；ghost、iconOnly、disabled、loading 默认 false；不再提供 block |
| Slots         | icon/default/suffixIcon 按序显示，空槽不占位；loading 替换前后图标并保留文字；iconOnly 只显示前图标或加载图标                                                                                                             |
| Events 与交互 | 可用时一次激活发出一次 MouseEvent click；鼠标、Enter、Space 共用原生激活路径；disabled/loading 阻止激活与波纹；保持原生焦点和表单语义                                                                                     |
| 边界          | text 忽略 ghost；退出加载恢复图标；连续激活重启波纹，切换不可用终止波纹；消费端 class/style 仍能设置普通按钮宽度                                                                                                          |
| 类型与出口    | 根入口与 button 入口继续提供 SButton、枚举、Props、Slots、Emits；ButtonProps 无 block，ButtonThemeTokens 无 ghostColorText；textColorText 和语义 Ghost 覆盖继续有效                                                       |

| 层级        | 适用性及推导范围                                                                                         |
| ----------- | -------------------------------------------------------------------------------------------------------- |
| unit        | 适用：默认值、输入组合、内容与事件、动态更新、源码类型和公共出口；只依据公共契约断言                     |
| integration | 适用：三档真实尺寸、消费宽度样式、颜色与主题覆盖、焦点、鼠标键盘一致性、波纹和 submit/reset 原生表单行为 |
| E2E         | 适用现有消费回归：dist 全量/按需安装、图标与按钮组合、加载提交、局部主题覆盖；不新增 Storybook E2E       |
| package     | 适用：公开字段删除需要验证声明、共享消费 Fixture、ESM/CJS、CSS、插件、导出映射和 npm 文件边界            |

Form 仅从 Storybook 移除，不删除原生表单测试。实际命令结果记录在 openspec/changes/archive/2026-09-09-simplify-button-and-stories/验证记录.md；未运行的检查不视为通过。

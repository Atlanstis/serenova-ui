# 主题公共契约与验证

实现依据为 `docs/styling-and-theming.md`。

| 对象                  | 公共契约                                                                               | 验证方式                                 |
| --------------------- | -------------------------------------------------------------------------------------- | ---------------------------------------- |
| Provider Props        | preset/tokens 缺省、inherit=true；显式预设和 false 重置；覆盖移除、undefined、输入不变 | unit + integration                       |
| Provider Slots/Events | 默认插槽可空或多子项，无业务事件，无 DOM 包装及 attrs 转发                             | unit                                     |
| Provider 类型/出口    | 根入口、单组件入口、插件注册和主题类型；null 非重置协议                                | unit + 包消费类型 Fixture                |
| Button Props          | variant/size/block/disabled/loading/nativeType 及默认值保持；主题响应式变化            | 既有 unit/integration + 主题 integration |
| Button Slots/Events   | 文案/icon、loading 输出、click 和原生表单行为保持                                      | 既有 unit/integration + 消费 E2E         |
| 鼠标/键盘/焦点        | Provider 不干预；Button 点击、Enter、Space 复用原生 click；保留焦点                    | integration                              |
| 主题边界              | 共享值先合并再派生；组件覆盖优先；同页隔离、继承重置及 Teleport                        | unit + integration                       |
| SSR                   | 输出变量、不同请求隔离、同输入 hydration 复用节点且无警告                              | unit + integration                       |
| 发布边界              | 子路径、模块、声明、CSS 依赖及副作用、无关规则排除、npm 范围                           | package                                  |
| 消费链路              | dist 全量/按需样式、主题切换及业务操作                                                 | E2E                                      |

四层均适用。断言基于公共输入、DOM、计算样式及业务结果，不访问私有状态。Provider 不新增独立无障碍体系；Teleport 使用最小 Fixture，不新增公共浮层。

## 源码目录重组验证

组件统一迁入 `src/components/`，组件主题定义与解析归入自身 `theme/`；共享预设迁入 `src/theme/presets/`，安装逻辑集中到 `src/plugin.ts`。公共行为与消费子路径保持不变，声明路径由包导出映射适配。

此次重组四层均适用：unit 验证公共出口和组件契约，integration 验证主题与焦点行为，E2E 验证 dist 消费，package 验证声明路径与样式依赖。已执行并通过 `pnpm type-check`（包含测试类型检查）、`pnpm test:unit`（26 项）、`pnpm test:integration`（7 项）、`pnpm test:e2e`（3 项）、`pnpm test:package`、`pnpm lint` 和 `pnpm format:check`。

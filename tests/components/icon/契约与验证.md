# 公共契约与验证

| 层级        | 本次范围                                                                                       |
| ----------- | ---------------------------------------------------------------------------------------------- |
| unit        | 公共 Props 默认值及组合、Slots、事件、SVG/按钮语义、动态更新、类型与安装导出；六个图标逐个验证 |
| integration | 真实尺寸与颜色继承、多实例；Button 焦点、键盘鼠标一致性、表单、Ghost、纯图标和动画状态         |
| E2E         | dist 全量/按需消费中组合图标与按钮，加载提交与局部主题覆盖                                     |
| package     | 根与 icons 集合入口、ESM/声明、无 CSS 图标、tree shaking 和文件边界                            |

Button：默认 primary/medium/button，布尔值默认 false；icon/default/suffixIcon 按序，loading 替换图标；iconOnly 保持所选尺寸正方形，text 忽略 ghost；空槽不产生占位。disabled/loading 均阻止原生业务激活，Enter/Space/鼠标复用 click。

图标：Add/Delete/Edit/Search/ArrowRight/Loading 均为独立 SVG，size 默认 24，color 缺省继承；无业务 Slots/Events，不新增焦点。验证显式颜色移除、数字及 CSS 尺寸、attrs、多实例。来源和哈希见 assets/icons/manifest.json，几何对照原始文件；不访问组件私有状态。

四层均适用，最终命令结果见变更目录的验证记录。

## 自动样式与客户端支持契约

公共 Props、默认值、Slots、Events、原生语义及类型出口保持不变。Button 使用时自动获得完整样式，无 Provider 回退浅色；Provider 保留默认插槽、无包装、响应式继承、重置和 Teleport 上下文。独立图标保持 size=24、currentColor、无业务插槽事件及无需 CSS，不携带按钮规则。边界新增多应用同文档样式去重、卸载后重挂载以及旧 CSS 入口移除。仅支持客户端，不再验证 SSR 或 hydration。

- unit 适用：输入输出、主题覆盖和默认回退、类型与导出沿用黑盒测试。
- integration 适用：真实计算样式、主题多应用隔离、动态状态及样式挂载生命周期。
- E2E 适用：dist 包根、子路径及插件无需 CSS 的真实消费，验证原生 style 覆盖及样式去重。
- package 适用：自动样式不能破坏 ESM、声明、自动样式、依赖边界、tree shaking 或 npm 文件范围；Node 导入不代表 SSR。

本次验证已通过：unit 66 项、integration 38 项、Chromium E2E 5 项，以及 package、类型检查、lint 和格式检查；最终样式专项复验通过。主规格已同步，临时变更目录已删除。

# 公共契约与验证

| 层级        | 本次范围                                                                                       |
| ----------- | ---------------------------------------------------------------------------------------------- |
| unit        | 公共 Props 默认值及组合、Slots、事件、SVG/按钮语义、动态更新、类型与安装导出；六个图标逐个验证 |
| integration | 真实尺寸与颜色继承、多实例；Button 焦点、键盘鼠标一致性、表单、Ghost、纯图标和动画状态         |
| E2E         | dist 全量/按需消费中组合图标与按钮，加载提交与局部主题覆盖                                     |
| package     | 根与 icons 集合入口、ESM/CJS/声明、无 CSS 图标、tree shaking 和文件边界                        |

Button：默认 primary/medium/button，布尔值默认 false；icon/default/suffixIcon 按序，loading 替换图标；iconOnly 保持所选尺寸正方形，text 忽略 ghost；空槽不产生占位。disabled/loading 均阻止原生业务激活，Enter/Space/鼠标复用 click。

图标：Add/Delete/Edit/Search/ArrowRight/Loading 均为独立 SVG，size 默认 24，color 缺省继承；无业务 Slots/Events，不新增焦点。验证显式颜色移除、数字及 CSS 尺寸、attrs、多实例。来源和哈希见 assets/icons/manifest.json，几何对照原始文件；不访问组件私有状态。

四层均适用，最终命令结果见变更目录的验证记录。
